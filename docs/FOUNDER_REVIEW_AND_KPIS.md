# Founder Review · KPIs and Evidence Rules

## Daily scorecard

| Metric | Who reports | Rule |
|---|---|---|
| Content published + reach, clicks | Pragati | Public-safe post evidence; no invented engagement |
| Unique colleges researched | Rupam | Deduplicate and keep private source-level records |
| Colleges contacted / replies / sessions confirmed / held | Rupam | Distinguish requested vs booked vs held |
| Unique student conversations + interested responses | Mannu Sharma | Permission-based; meaningful replies, no bought lists |
| Demo invites, booked demos, held demos / attendance | Shrushti | Never mix bookings with demos held |
| Registration started / completed / accessible / onboarded | Shrushti | Verify against product records, not word-of-mouth |
| Successfully connected unique students | Shrushti → Pragati | Count ONLY verified interest + registration + access + onboarding |
| Lead handoffs and overdue follow-ups | Pragati | Private tracker handles identities; aggregate on GitHub |

## Founder review rhythm

- **Every day:** Pragati's summary and 4 issue reports; review blocker owner, approvals and next steps.
- **Day 05:** analyse pipeline, channels and first conversion bottleneck; adjust assumptions.
- **Day 10:** compare message tests, college replies, content results and reasons for stalled registrations.
- **Day 15:** audit the final 10+ connected-student target and next-phase 15-day plan. Clearly report target missed if applicable.

## Funnel formula examples

- Reply rate = genuine replies / unique contacted students (when denominator > 0).
- Interest rate = genuinely interested / genuine replies (when denominator > 0).
- Registration start-to-completion = completed registrations / starts (when denominator > 0).
- Onboarding conversion = verified successfully connected unique students / unique student contacts (when denominator > 0).
- When denominator = 0, write **N/A**; never invent a percentage.

## Lead tracker (private ONLY)

Fields: unique ID; owner; student identity/contact details (only if voluntarily provided, compliant and necessary); source/channel; permission status; contact date; first reply; interested; demo date; registration attempted; registration verified; account access verified; onboarding verified; next action; opt-out; actual feedback. Limit access to authorised staff. Do not share contact lists or product-identifying records in a public issue.

## Approved claims register (private founder-controlled)

Each claim: exact wording, feature or price status, evidence date, founder approval date, expiry/re-test date. Do not advertise a 7-day trial, ₹999 pricing, placements, certificates, internship experience, guarantees or security certifications unless currently verified and authorised.
