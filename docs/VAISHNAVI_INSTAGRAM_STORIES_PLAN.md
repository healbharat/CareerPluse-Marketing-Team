## Content tools and format

- Use **Canva** for brand-kit-compliant 1080 × 1920 Story visual design with mobile-readable text.
- Use Instagram's built-in **Poll, Quiz, Questions, Emoji Slider** stickers where the product supports them. Adjust question formats to the sticker capabilities; don't fabricate published or voted results.
- Target: one manager-approved ready-to-post interactive Story concept or sequence per planned working day, depending on account access and review.
- Relevant example copy: “Python vs Java?”, “AI, Web Development or Data Science?”, “Hours spent learning new skills each week?”, “Biggest difficulty finding internships?”, “Guess this programming language!”, “Which skills do you want to develop next?”
- Questions are optional and should avoid requesting students' names/phone numbers. Use anonymous summary metrics publicly.
