# Public-safe daily report — paste as a comment on your daily GitHub Issue

```text
CareerPluse | Day: 00 | Date: YYYY-MM-DD | Owner:
Fixed Role:
STATUS: In Progress / Blocked / Ready for Review

1. ASSIGNED ACTIONS: [total]
2. COMPLETED ACTIONS: [total + 1-line explanation each]
3. TARGET VS ACTUAL: [use numbers; 0 when none]
4. KEY RESULTS: [posts / colleges researched / conversations / demos / verifiable onboarding; only applicable role]
5. SAFE EVIDENCE: [public links to approved posts/designs/agenda; no private identities]
6. HANDOFFS: [counts and owner, not lead identities]
7. BLOCKERS: [technical/approval problem and who needs to resolve it]
8. TOMORROW'S NEXT ACTION: [specific]
9. FOUNDER APPROVAL: Pending / Changes requested / Approved
```

## Example: Mannu Sharma (illustrative — do not pass off as actual)

```text
Day: 03 | Status: Ready for Review
Target: up to 10 relevant permission-based personalised contacts
Actual: 8 contacts, 3 replies, 2 genuinely interested, 1 opted-in demo handoff
Evidence: outreach log reference in PRIVATE tracker; only these aggregate counts shared publicly
Blocker: approved pricing FAQ not yet available
Next: hand off 1 demo to Shrushti privately, continue 2 warm replies
```

## REQUIRED: additional paid and business conversion reporting fields

Append the following to the existing GitHub Issue comment. These are **aggregate numbers only**, not customer/payment identities. Source records remain private.

```text
PAID STUDENTS (TODAY): successful verified and onboarded __ | refunds/reversals __ | net new __
NET VERIFIED PAID & ONBOARDED (CUMULATIVE): __ / 15
PAYMENT / SIGNUP BLOCKERS: __
BUSINESS PROSPECTS (RUPAM): researched __ | qualified __ | approached __ | replied __ | meetings held __
BUSINESS APPROACHED CUMULATIVE: __ / 1
TRACKER RECONCILED: Yes / No | FOUNDER APPROVAL: Pending / Approved / Changes
```

A paid student is verified only after a successful authorised payment, registration, account access and initial onboarding, excluding reversed/refunded accounts from the net active total. A business approach counts only after an actual personalised first outreach was sent. Refer to [the new conversion playbook](PAID_ACQUISITION_AND_BUSINESS_OUTREACH.md).
